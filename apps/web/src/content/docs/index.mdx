FluxMedia 只提供图片与视频生成能力。站内页面与外部 API 共用统一接口层、媒体管线、
积分账本、对象存储和统一后端号池。

## 官方参考

- **[系统文档（含外部 API）](/docs/system)** — 统一媒体链路、安全边界、图片与视频路由、任务查询和积分入口。

## 其他参考

- **[统一媒体号池与 Adobe 路由](/docs/adobe-firefly-routing)** — API 与 Adobe 成员如何通过显式模型能力进入同一候选集合，以及 Adobe direct 视频恢复边界。

## 快速开始

1. 在控制台创建 API Key，并将它绑定到允许的媒体分组。
2. 阅读 [系统文档](/docs/system) 的鉴权、安全和幂等规则。
3. 图片调用 `POST /v1/images/generations` 或 `POST /v1/images/edits`。
4. 视频调用 `POST /v1/videos/generations` 并提供 `clientRequestId`，再轮询
   `GET /v1/videos/{taskId}`。
