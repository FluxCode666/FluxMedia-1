## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器 → 本地化 admin 页面 | 未登录、普通用户和伪造客户端路由请求进入服务端页面守卫。 |
| 页面面板 → Server Action/UOL | 客户端筛选、按钮和只读状态均是不可信输入，Action/UOL 必须重新校验 Principal。 |
| 管理员 → 系统设置写入 | 系统设置包含认证密钥等高敏配置，页面可见性不能替代服务端权限。 |

</threat_model>
