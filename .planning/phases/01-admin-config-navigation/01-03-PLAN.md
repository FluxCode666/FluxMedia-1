## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器 → supplier-groups Server Component | 未登录、普通用户或伪造 locale 路由请求试图读取分组、分页和计费覆盖数据。 |
| 分组/成员客户端面板 → Server Action/UOL | 客户端 readOnly 状态、表单输入和 URL 查询参数均不可信，不能决定写权限或领域执行。 |
| image-backend-pool mutation → 两个缓存路由 | 一次成员或分组修改会影响另一个页面的归属、计数、下拉选项或计费展示。 |
| pathname/locale → 侧栏 active 逻辑 | 不可信 URL 不能通过旧页签参数或父级路径误导管理功能与 active 指示。 |
